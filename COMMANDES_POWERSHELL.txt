═════════════════════════════════════════════════════════════════════════════════

  .\.venv\Scripts\python.exe services/api_moyennes.py

❌ SI ERREUR
═════════════════════════════════════════════════════════════════════════════════

❌ "python.exe not found"
  → Assurez-vous d'être dans le bon dossier
  → Vérifiez que .\.venv\Scripts\python.exe existe
  → Ou installez Python depuis python.org

❌ "npm: command not found"
  → Installez Node.js depuis nodejs.org
  → Redémarrez le terminal après installation
  → Vérifiez : npm --version

❌ "Port 8001 already in use"
  → Stop-Process -Name python -Force
  → Attendez 2 secondes et relancez

❌ "Port 3000 already in use"
  → Stop-Process -Name node -Force
  → Attendez 2 secondes et relancez

❌ "Cannot find module"
  → npm install
  → npm start
