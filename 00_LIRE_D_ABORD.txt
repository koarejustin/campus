⚡ ARCHITECTURE TECHNIQUE
═══════════════════════════════════════════════════════════════════════════════════

FLUX DE DONNÉES :

  Client (Vue.js)
    ↓ HTTP/WebSocket
  Express.js (Port 3000)
    ↓ HTTP
  FastAPI Python (Port 8001)
    ↓ SQL
  PostgreSQL (Port 5432)

CALCUL :

  Notes de l'élève (Base de données)
    ↓
  Moteur Python récupère les notes
    ↓
  Applique formule : (80% compositions + 20% devoirs) × coefficient
    ↓
  Calcule moyenne générale, évolution, prédictions, alertes
    ↓
  Cache résultats dans historique_moyennes
    ↓
  Retourne JSON à Express.js
    ↓
  Express.js envoie à Vue.js
    ↓
  Vue.js affiche avec Chart.js

❓ QUESTIONS FRÉQUENTES
═══════════════════════════════════════════════════════════════════════════════════

Q : Comment je relance les services demain ?
A : Cliquez sur demarrer.bat, c'est tout !

Q : Comment je vois les erreurs ?
A : Consultez logs_python.txt et logs_nodejs.txt

Q : Les ports 8001 et 3000 sont bloqués, que faire ?
A : Voir GUIDE_DEMARRAGE.md → Section TROUBLESHOOTING

Q : Je veux modifier les coefficients, où ?
A : Dans la base de données → pedagogie.coefficients_par_classe

Q : Comment on ajoute une nouvelle matière ?
A : Dans la base de données → pedagogie.matieres + coefficients

Q : Comment on change le nombre de trimestres ?
A : Dans .env → TRIMESTRES_PAR_AN=3 (ou autre nombre)

Q : Les graphiques ne s'affichent pas ?
A : Installer Chart.js : npm install chart.js vue-chartjs
